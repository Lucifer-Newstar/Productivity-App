# Kaizen 🌸

Monorepo for the Kaizen productivity / life-OS app.

```
productivity-app/
├── frontend/    # Next.js app (see frontend/README.md)
└── backend/     # (coming later)
```

## Getting started

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `frontend/` — Next.js 14 + TypeScript + Tailwind + Framer Motion
- `backend/` — reserved for a future API / server (discussed later)
