# Public-safe Wave 0 aggregates

Only reviewed outputs created by `scripts/sanitize_results.py` may be placed here.

Allowed files contain aggregate hardware class, benchmark metrics, reliability rates and recommendations. They must not contain raw prompts/responses, per-sample telemetry, user/home paths, hostnames, serials, UUIDs, MACs, credentials, model files or Kaizen user data.

Raw artifacts belong in ignored `../results-local/` and stay on the owner's machine.
