# v0.1.1 public evaluation aggregates

This directory contains reviewed aggregate results generated from public synthetic fixtures only.

Accepted files must declare:

```json
"classification": "PUBLIC-SANITIZED-AGGREGATE"
```

No personal Kaizen data, prompts, model logs, hardware identifiers, credentials, local paths or raw benchmark artifacts belong here. `deterministic-mock-implementation.json` is reproducibly generated by `npm run eval:v0.1.1`; it evaluates the deterministic mock implementation and is not evidence of real-model selection.
