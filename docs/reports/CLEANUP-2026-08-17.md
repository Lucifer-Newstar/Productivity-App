# Repository cleanup and documentation reorganization — 2026-08-17

## Code removed

The following UI modules had no route, import, dynamic loader or JSX caller and were removed after a repository-wide reference scan:

- `components/SpaceTasks.tsx` — superseded after Health and Entertainment gained dedicated shells.
- Legacy Career `AchievementVault`, `CareerNotes`, `Goals`, `Posts`, `Roadmap` and `TrackTabs` components — superseded by the current nine sector modules.
- `components/workout/WorkoutExercises.tsx` — superseded by the routed library/editor implementation.

The obsolete Career action surface used only by those removed components was also deleted from `StoreState`, callback implementations and provider values. Legacy Career data fields remain in migration/state so existing browser data is not discarded.

The unused global `markAllNotificationsRead` store action and `useSpace` helper were removed; contextual mark-all behavior now lives in NotificationCenter where section visibility is known.

Approximate reduction: more than 1,700 source lines without removing a routed feature.
