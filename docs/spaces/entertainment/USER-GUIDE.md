# AFTERGLOW user guide

## Add media

Use **Quick Add**:

- Catalogue Search selects one of six media types and queries its configured provider.
- Manual creates a title without provider metadata and supports a validated local cover.

Catalogue imports begin in Planned status. Duplicate provider IDs are blocked.

## Track a title

Open a card to edit status, rating, dates, progress, repeats, priority/order, franchise, countries, notes, review, tags and purchase price. Media-specific controls appear below the generic fields.

- Books: log pages/minutes to calculate pace and ETA.
- Comics/manga: set totals and toggle owned/read volumes.
- Series/anime: create season totals and log/rate episodes.
- Movies: record venue/version and acting/cinematography scores.
- Anime: record source, audio, seiyuu, studio and OP/ED preferences.

Provider Refresh updates catalogue metadata only; it does not overwrite personal tracking.

## Organize

- **Library:** full-text and compound filters.
- **Collections:** cross-media custom shelves.
- **Calendar:** release/schedule month grid and `.ics` export.
- **History:** immutable local action timeline.
- **Archive:** restore/permanent delete plus backup/import/export.

## Discover

Discover contains local intelligence and provider charts:

- If-you-liked
- Mood pick / Surprise Me
- Exploration score and blind spots
- Franchise gaps
- Creator marathons
- Live provider trending

Local intelligence never sends private library state to a recommendation service.

## Stats

Stats covers counts/time, ratings, genre/creator/decade/month/year, backlog, abandoned reasons, activity, moods, cost and satisfaction.

## Social

Friends, taste match, recommendations, groups, prompts, gifts and loans are manually entered offline records. They are not shared publicly.

## Studio

Create review drafts, fan art/fiction, cosplay logs, quotes, mood boards, dream casts and what-if scenarios. Image uploads are raster-only and use browser storage.

## Provider setup

Open **Providers & Credits** for server configuration status and temporary tab-session overrides. See [`APIS.md`](APIS.md) and [`../../guides/CONFIGURATION.md`](../../guides/CONFIGURATION.md).

## Backup

Use Archive → Data Vault to export JSON before clearing browser data or removing large images. See [`../../guides/DATA-BACKUP-RESTORE.md`](../../guides/DATA-BACKUP-RESTORE.md).
