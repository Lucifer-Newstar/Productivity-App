# Kaizen glossary

| Term | Meaning |
|---|---|
| Kaizen | The complete productivity/life OS |
| Space | A major product domain inside the single frontend |
| Forge | Display brand for the Projects space |
| Foundry | Forge project dashboard |
| Quarry | Forge task planning/kanban |
| Smelter | Forge ideation, retrospectives and strategy canvases |
| Vault | Forge archive/import/export area |
| VITAL-SIGN | Health dark full-screen theme/product identity |
| Clinic | Health light theme |
| Triage | Health landing dashboard |
| Fuel | Nutrition section |
| Somnium | Sleep section |
| Soma | Physique/body-composition section |
| Apothecary | Supplements section |
| Sync Lab | Health profile and Workout bridge settings |
| AFTERGLOW | Entertainment media OS |
| Midnight Screening | AFTERGLOW dark theme |
| Matinee | AFTERGLOW light theme |
| Provider adapter | Fixed same-origin server integration for an external catalogue |
| BYOK | Bring your own provider key; AFTERGLOW stores overrides for one tab session only |
| FULLSCREEN | Page static flag that bypasses shared `TopNav`/container chrome |
| Root store | React Context provider containing all persisted state slices/actions |
| Migration | Function that converts older persisted state to the current defensive shape |
| Local-first | Browser state is primary; the product works without Express/cloud sync |
| Bridge | A controlled cross-space read/write contract, especially Health ↔ Workout and Forge → Career |
