# Kaizen v1.0.0

Kaizen v1.0.0 is the first local-first Windows release of the productivity and life-OS application.

## Included

- Home command center with tasks, notes, habits, calendar and focus timer.
- Forge project workspace.
- Career planning and evidence tools.
- Workout tracking and progression.
- VITAL-SIGN Health workspace.
- AFTERGLOW Entertainment workspace.
- Whole-product browser backup, restore and corruption recovery.
- Read-only deterministic Core Today intelligence through a bundled loopback engine.
- One per-user Windows x64 setup executable with desktop/Start Menu shortcuts, registered uninstall and release-driven update notifications.

## Privacy and architecture

- Product records remain in the selected browser profile at the fixed local origin.
- Browser records are not encrypted by Kaizen; use a trusted Windows account and browser profile.
- No cloud account, remote AI provider, model runtime, AI memory, Health AI, AI writes or automation is included.
- The Express reference API is not included in the installer.
- Uninstall removes installed application files and shortcuts but intentionally leaves browser-profile records.

## Installation

1. Download the setup executable and `.sha256` file.
2. Verify the SHA-256 checksum.
3. Run the setup executable as the intended Windows user.
4. Launch Kaizen from the desktop or Start Menu.

See `docs/guides/WINDOWS-INSTALLATION.md` for complete instructions.

## Verification

Release assets are built on a Windows runner, silently installed, tested across all 39 routes and deterministic Core Today, silently uninstalled, and accompanied by sanitized package and delivery manifests.

## Known limitations

- The setup executable is not Authenticode-signed unless the delivery manifest reports a valid signature; Windows SmartScreen may show an unknown-publisher warning.
- Entertainment metadata provider features require network access and optional provider credentials.
- Browser storage is finite and tied to the fixed local origin and browser profile.
- Closed-app notifications and cloud synchronization are not included.
